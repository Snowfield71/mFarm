# 萌田农场 Cocos 客户端

## 环境

- Cocos Creator 3.8.x（当前开发版本为 3.8.8）
- TypeScript
- 竖屏设计分辨率：`360 x 640`

## 启动

1. 使用 Cocos Creator 打开本 `Web` 目录。
2. 打开项目已有主场景。
3. 点击编辑器顶部“预览”运行。
4. 首次启动等待 TypeScript 编译和 UI 图片预加载完成。

项目已包含场景和脚本，不需要重新新建场景或手动把 `GameManager.ts` 拖到空 Canvas。

## 当前功能

- 农场：选择作物、种植、成长、收获与扩地。
- 物品栏：全部、种子、材料、成品分类和出售。
- 合成：配方选择、材料校验、制作队列和进度恢复。
- 任务：主线、每日、支线、特殊任务，前往、详细和领奖。
- 图鉴：`3 x 3` 分页、等级/发现遮罩和收集进度。
- 好物集市：种子与工具分类购买。
- 每日签到：七日循环奖励、可领取红点和断签重置。
- 成就手册：完成状态、头像红点和金币/钻石奖励领取。
- 工具与建筑：工具消耗效果、建筑放置、拆除和定时生产。
- 存档：等级、货币、背包、土地、合成、任务、图鉴、签到和成就保存到 `localStorage`。

底部导航固定为：物品栏、合成、任务、图鉴。

## 目录

```text
Web/assets/scripts/
├─ config/       # 游戏数值、物品、配方和任务
├─ core/         # GameManager、DataManager、EventManager
├─ systems/      # 土地、背包、合成、货币和等级
├─ ui/           # 主界面、面板与绘制工具
└─ utils/        # 图片缓存等公共工具
```

图片源文件位于 `../Server/assets/textures/`，UI 逻辑路径统一维护在 `assets/scripts/utils/ImageCache.ts`。

## 调试默认值

当前 `GameConfig.ts` 为界面压力测试设置：

- 等级：99
- 金币：10,000,000
- 钻石：10,000,000

发布前应根据正式数值方案恢复默认账户数据，并测试旧存档兼容。

## 修改后检查

1. 控制台无资源加载和 TypeScript 错误。
2. 物品栏、合成、任务、图鉴、商店、签到和成就面板可正常开启、切换和关闭。
3. 完成一次种植、收获、合成和任务领取。
4. 刷新后确认存档恢复。
5. 在窄屏和宽屏预览中确认面板贴合底部导航且图片清晰。
