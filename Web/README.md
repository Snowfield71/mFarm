# 🌾 萌田农场 - 游戏项目

## 快速启动（5步）

### 第一步：用 Cocos Creator 3.8.8 打开项目

启动 Cocos Creator → 选择 **打开项目** → 选择本 `Web` 目录

### 第二步：新建场景

在 Cocos Creator 菜单栏点击：
```
文件(File) → 新建场景(New Scene)
```
你会看到一个带有 `Canvas` 节点的空场景。

### 第三步：挂载脚本

1. 在 **层级管理器(Hierarchy)** 中点击选中 `Canvas` 节点
2. 在 **资源管理器(Assets)** 中找到：
   ```
   assets → scripts → core → GameManager.ts
   ```
3. **按住 `GameManager.ts` 拖拽** 到右侧 **属性检查器(Inspector)** 中
   - 你会看到属性面板出现 "GameManager" 组件
   - 如果没反应，也可以拖到 Canvas 节点上松开

### 第四步：保存场景

```
文件(File) → 保存场景(Save Scene)
```
保存到：`assets/scenes/Main.scene`（如果 `scenes` 文件夹不存在就先创建它）

### 第五步：运行

点击编辑器顶部中间的 ▶ **运行** 按钮

> ⏳ 首次运行需要几秒编译 TypeScript，请等待。
> 如果控制台有报错，截图给我看。

## 游戏操作

| 操作 | 说明 |
|------|------|
| 🌱 点击空地 | 种植作物（需要有种子） |
| ⭐ 点击已成熟地块 | 收获作物到背包，获得经验 |
| 🎒 底部"物品" | 打开背包，点击物品可出售 |
| ⚙️ 底部"合成" | 选择配方合成高级物品 |
| 🏪 底部"商店" | 购买种子 |
| 底部"种植" | 选择种子后点击地块种植 |

## 文件结构

```
Web/assets/scripts/
├── config/          # 游戏配置（配色/物品/配方）
├── core/            # 核心引擎（GameManager/DataManager/EventManager）
├── systems/         # 游戏系统（地块/背包/合成/货币）
├── ui/              # 用户界面（主UI/物品栏/合成台/商店/弹窗）
├── entities/        # 实体对象
└── utils/           # 工具
```
